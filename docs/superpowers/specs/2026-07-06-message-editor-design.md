# MessageEditor: حقل تحرير احترافي لرسائل الترحيب والوداع

**التاريخ:** 2026-07-06 · **الحالة:** معتمد

## الهدف

استبدال حقلي النص العاديين (رسالة الترحيب ورسالة الوداع) في WelcomeTab بمكوّن
`MessageEditor` واحد يوفر: أزرار تاغات تُدرج `{user}`/`{server}`/`{count}` عند
موضع المؤشر، لوحة إيموجي منسقة (~120 إيموجي بلا مكتبات خارجية)، معاينة حية
بقيم تجريبية، مع بقاء حد الـ500 حرف والعدّاد.

## التصميم

- `components/MessageEditor.tsx` — Props: `label`, `hint`, `value`,
  `onChange`, `maxLength`, `rows`, `sampleUser`.
- شريط أدوات: ثلاثة أزرار تاغات (اسم العضو، اسم السيرفر، عدد الأعضاء) وزر
  إيموجي يفتح Popover بشبكة مجمّعة (وجوه، ألعاب، قلوب، رموز). يُغلق بـ
  Escape أو النقر خارجه.
- الإدراج يحترم موضع التحديد (`selectionStart/End`)، يعيد التركيز ويضبط
  المؤشر بعد النص المُدرج، ويرفض الإدراج إذا تجاوز `maxLength`.
- معاينة حية أسفل الحقل: استبدال التاغات بقيم تجريبية (اسم المستخدم الحالي،
  «سيرفرك» المترجمة، 128).
- مفاتيح ترجمة جديدة في اللغات الست: `editor.tag.user/server/count`,
  `editor.emoji`, `editor.preview`, `editor.sampleServer` — اختبار اكتمال
  اللغات الحالي يضمن التطابق.

## الاختبارات

إدراج تاغ عند المؤشر (وسط النص)، إدراج إيموجي، رفض الإدراج فوق الحد،
فتح/إغلاق لوحة الإيموجي بالنقر وEscape، صحة المعاينة، وبقاء اختبارات
WelcomeTab الحالية (maxLength + العدّاد) خضراء.
