# GameBot — مواصفات التصميم (الإصدار الأول v1)

**التاريخ:** 2026-07-04
**الحالة:** معتمد (جلسة عصف ذهني)
**الاسم:** «GameBot» اسم عمل مؤقت — يُستبدل عند اختيار اسم المنتج.

## 1. نظرة عامة

بوت ديسكورد عربي موجّه لسيرفرات القيمنق العربية/الخليجية كمنتج عام (multi-guild). تخصص الإصدار الأول:

1. **الكستمز والسكرمات** — إدارة مباريات مخصصة كاملة الدورة (لوبي → توزيع فرق → رومات فويس → نتيجة → نقاط ولوحة صدارة).
2. **المساعد الصوتي الذكي** — بوت يسمع ويرد صوتيًا بالعربية (لهجات قابلة للضبط) داخل الفويس، بكلمة تنبيه، مع تكامل صوتي مع ميزات الكستمز.

### قرارات الجلسة

| القرار | الاختيار |
|---|---|
| الهدف | منتج عام للسيرفرات العربية (وليس بوتًا شخصيًا) |
| نطاق v1 | الصوتي الذكي + الكستمز/السكرمات + لوحة صدارة |
| المراحل اللاحقة | v1.5: لوحة تحكم ويب · v2: إدارة/حماية بالعربي · v3: إحصائيات الألعاب |
| المعمارية | إعادة كتابة من الصفر (monorepo) مع **نقل** منطق الصوت المجرّب من `D:\dev\discord-bot` |
| لوحة التحكم | لا يوجد في v1 — الضبط عبر `/settings` داخل ديسكورد |
| قاعدة البيانات | MongoDB Atlas |

## 2. المعمارية

pnpm workspace (جاهز لإضافة الداشبورد في v1.5):

```
gamebot/
├── apps/bot/            # عميل discord.js v14 + TypeScript
│   └── src/
│       ├── modules/     # وحدات معزولة: customs/, voice-ai/, settings/
│       ├── commands/    # تسجيل Slash commands (لكل وحدة ملفها)
│       ├── events/      # interactionCreate, voiceStateUpdate, ready...
│       └── lib/         # client, i18n, permissions, quotas
├── packages/db/         # نماذج Mongoose + طبقة Repositories
└── packages/shared/     # Zod schemas + أنواع مشتركة
```

### المبادئ

- **عزل بـ `guild_id`:** طبقة Repositories تفرض `guildId` كمعامل إجباري في كل استعلام؛ لا وصول مباشر للـ Models من الأوامر.
- **لا حالة عامة خارج نطاق الـ guild:** جلسات الصوت والكستمز في Maps مفتاحها `guildId` — يجعل تفعيل Sharding لاحقًا (عند ~2,000 سيرفر) بلا إعادة كتابة. الـ Sharding نفسه خارج نطاق v1.
- **التحكم بالتكلفة:** طبقة Quotas مركزية — حدود يومية لكل سيرفر (دقائق استماع، أسئلة AI)، عدّادات في Mongo، رسالة واضحة عند النفاد.
- **تجريد المزوّدين:** واجهة `AIProvider` — Groq وGemini في v1 (منقولة من البوت القديم)، إضافة مزوّد جديد = ملف واحد.
- **التشغيل:** Docker؛ `.env` للأسرار العامة فقط (توكن البوت، مفاتيح AI، `MONGODB_URI`) — كل إعدادات السيرفرات في القاعدة.

## 3. نماذج البيانات (Mongoose)

- **GuildConfig** — `guild_id` (unique)، `language` (ar افتراضي)، `voice`: `{ enabled, wake_word: 'يا بوت', dialect: 'gulf'|'syrian'|'egyptian'|'msa', allowed_channel_ids[] }`، `customs`: `{ win_points: 25, loss_points: -10, admin_role_id }`، `quotas`: `{ listen_minutes_per_day: 60, ai_questions_per_day: 50 }`.
- **Player** — `guild_id` + `user_id` (compound unique)، `points`، `wins`، `losses`، `last_played`.
- **Match** — `guild_id`، `creator_id`، `game`، `team_size`، `balance_mode: 'random'|'balanced'`، `players[]`، `team_a[]`/`team_b[]`، `status: 'lobby'|'in_progress'|'completed'|'cancelled'`، `winner`، `temp_channel_ids[]`، `lobby_message_id`، طوابع زمنية.
- **UsageCounter** — `guild_id`، `date`، `listen_seconds`، `ai_questions` (فهرس مركّب + TTL للتنظيف).

## 4. وحدة الكستمز (`modules/customs/`)

### الدورة الكاملة

1. **`/custom create`** — خيارات: اللعبة (فالورانت/كود/فورتنايت/أخرى)، حجم الفريق (1–10)، التوزيع (عشوائي/متوازن). ينشئ Embed لوبي بأزرار: **انضمام / انسحاب / بدء** (البدء للمنشئ أو الإدارة). مباراة نشطة واحدة لكل سيرفر في v1.
2. **البدء** — التوزيع: عشوائي، أو متوازن بالنقاط (ترتيب تنازلي ثم توزيع تعرّجي Snake). إنشاء رومين فويس مؤقتين (فريق أ/ب) تحت كاتيجوري اللوبي ونقل اللاعبين تلقائيًا. Embed يعرض التشكيلتين.
3. **`/custom result winner:<team>`** — للمنشئ أو الإدارة: تسجيل النتيجة، توزيع النقاط من `GuildConfig`، تحديث سجل اللاعبين، حذف الرومات المؤقتة.
4. **`/custom cancel`** — إلغاء وتنظيف بلا نقاط.
5. **الإغلاق التلقائي** — مباراة بلا نتيجة خلال 3 ساعات تُغلق بلا نقاط (مهمة دورية + استرجاع عند الإقلاع).

### العرض والتتويج

- **`/leaderboard`** — أعلى 10 لاعبين بالنقاط (Embed).
- **`/profile [@عضو]`** — النقاط، فوز/خسارة، نسبة الفوز، آخر المباريات.

## 5. وحدة المساعد الصوتي (`modules/voice-ai/`)

منقول من `D:\dev\discord-bot` (STT عبر Groq Whisper، TTS، wake word) ومُعمَّم لكل سيرفر:

- **الضبط عبر `/settings`:** تفعيل/تعطيل، كلمة التنبيه (افتراضي «يا بوت»)، اللهجة (تُحقن في System Prompt)، القنوات الصوتية المسموحة.
- **الأوامر:** `/join` (دخول + استماع)، `/leave`، `/ask` (سؤال AI بردّ صوتي)، `/speak` (نطق نص)، `/chat` (نص فقط).
- **أوامر صوتية بعد كلمة التنبيه:** ساعد، اطلع، اسكت، قل، اسأل — **ووزّع الفرق**: إن وُجدت مباراة كستم في حالة لوبي ينفّذ بدأها (توزيع + رومات + نقل)، وإلا يوزّع أعضاء الروم الصوتي الحالي توزيعًا سريعًا في رسالة فقط (بلا مباراة ولا نقاط). نقطة التكامل المميزة بين الوحدتين.
- **الحصص:** افتراضي 60 دقيقة استماع + 50 سؤال AI لكل سيرفر يوميًا؛ عند النفاد رسالة واضحة. (رفع الحدود كـ Premium خارج نطاق v1.)

## 6. عام

- **i18n:** عربية أولًا في كل الردود والـ Embeds؛ بنية i18n (ملفات JSON) جاهزة لإضافة الإنجليزية.
- **الصلاحيات:** أوامر الضبط والنتائج لمن يملك Manage Server أو الرول الإداري المحدد في `GuildConfig` (درس مستفاد من البوت القديم: الرول وليس الصلاحية فقط).
- **معالجة الأخطاء:** defer لكل تفاعل خلال 3 ثوانٍ؛ فشل مزوّد AI → المزوّد البديل → رسالة اعتذار؛ إقلاع البوت يسترجع المباريات النشطة من Mongo وينظف الرومات اليتيمة.
- **الاختبارات (Vitest):** خوارزمية التوزيع المتوازن، حساب النقاط، طبقة الحصص، عزل الـ guild في الـ Repositories (استعلام بسيرفر مختلف لا يرى البيانات)، وتحليل كلمة التنبيه.

## 7. خارج نطاق v1 (مثبت)

- لوحة تحكم ويب (v1.5)
- بطولات بأقواس إقصاء (v2)
- الإدارة/الحماية بالعربي (v2)
